# EPIC
Electron-phonon coupling in narrow bands intermetallics

EPIC contyains a suite of scripts that can be used to compute the electron-phonon coupling (EPC) and parametrize it into deformation potential values, for narrow band systems. EPIC extends the methodology conytained in the EPHOS repository for organic semiconductor. The EPC is computed as a bandwidth modulation over the phonon eigenmode coordinates, thus it can be applied when the bands are narrow. Morde-resolved EPC values are then DOS-weighted averaged over the BZ points. 

The current version of EPIC is under development and testing.
